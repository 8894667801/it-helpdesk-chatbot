# 🤖 IT Helpdesk Chatbot

> **Smart Troubleshooting Assistant** — Get instant, step-by-step help for common IT issues.

🔗 **Live:** [https://8894667801.github.io/it-helpdesk-chatbot/](https://8894667801.github.io/it-helpdesk-chatbot/)

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📧 **Outlook Issues** | 30+ troubleshooting guides — from OST corruption to Teams add-in fixes |
| 🪟 **Windows & Cache** | Temp file cleanup, cache clearing, profile repair |
| 🔄 **System Updates** | Windows Update, driver updates, restart best practices |
| ☁️ **Microsoft 365** | Password reset, MFA, sign-in, and licensing |
| 💻 **Device Health** | Disk cleanup, slow PC diagnosis, safe troubleshooting |
| ☁️ **AWS Access** | Server login rules, VPN, environment credentials |

### More Highlights

- 🔍 **NLP-Lite Engine** — Type your issue in plain language and get matched solutions
- 🌗 **Dark / Light Theme** — Toggle with one click, preference saved
- 📱 **Mobile Responsive** — Works beautifully on phones and tablets
- ⚡ **Zero Dependencies** — Pure HTML, CSS, and JavaScript — no frameworks needed
- 🎨 **Premium UI** — Glassmorphism, smooth animations, gradient accents
