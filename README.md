# IT Helpdesk Chatbot 🤖

A smart, friendly IT Helpdesk Chatbot that guides users step-by-step to troubleshoot and fix common IT problems.

## Features

- **23 troubleshooting guides** across 5 categories
- **Smart text matching** — type your problem in plain language
- **Step-by-step solutions** with warnings and verification steps
- **Dark/Light theme** toggle
- **Mobile responsive** design

## Categories

| Category | Issues Covered |
|----------|---------------|
| 📧 Outlook | Not opening, stuck loading, profile corrupted, OST/PST, safe mode |
| 🪟 Windows | Temp files, cache clearing, temp profile fix, recreate profile |
| 🔄 Updates | Windows updates, optional updates, drivers, restart best practices |
| ☁️ Microsoft 365 | Password reset, MFA, sign-in, license issues |
| 💻 Device Health | Disk cleanup, performance, safe troubleshooting, restart vs shutdown |

## How to Use

1. Visit the live site
2. Choose a category or type your problem
3. Follow the step-by-step solution
4. Use feedback buttons to confirm fix or escalate

## Tech Stack

- HTML5, CSS3, Vanilla JavaScript
- No frameworks, no dependencies, no build step
